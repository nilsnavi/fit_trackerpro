# FTP-021. Основа Premium UI

## Changelog

- Добавлены графитовые поверхности, лаймовый акцент и Manrope в существующую тёмную тему веб-версии и PWA. Тёмную и светлую темы можно переключать в верхней панели веб-версии. Шрифт упаковывается со статикой приложения, доступны кириллица и латиница.
- На широком экране тёмная веб-тема использует боковую навигацию. На узком экране панель остаётся снизу. Ссылки ведут в существующие разделы.
- Telegram Mini App использует свою светлую или тёмную тему и нижнюю навигацию.

## Границы PR A

Эталон описывает четыре вкладки спортсмена и четыре вкладки тренера. На этапе A перенесены палитра, шрифт и адаптивная оболочка. Текущие ссылки «Главная», «Каталог», «Тренировки», «Прогресс» и «Профиль» сохранены. Детали главной, тренировки, программ и аналитики относятся к PR B–D. Навигация и страницы кабинета тренера относятся к PR E–F. Демо-переключатель ролей, данные и CTA прототипа не подключаются.

| Вкладка эталона | Маршрут FitTracker |
| --- | --- |
| Athlete → Обзор | `/home` |
| Athlete → Тренировка | `/workouts`, `/workouts/active/:id` и экран итога |
| Athlete → Программы | `/workouts/templates` и `/client/coach-programs` |
| Athlete → Прогресс | `/analytics` и `/progress` |
| Coach → Обзор, Клиенты | `/coach`, `/coach/clients` и `/coach/monitoring` |
| Coach → Программы | `/coach/programs` |
| Coach → Расписание | В эталоне показан недельный календарь встреч. В проекте есть задачи тренера, для встреч отдельного контракта пока нет. |

## Проверка и откат

`frontend/e2e/premium-shell.spec.ts` проверяет адаптивную навигацию, переход по действующему маршруту, уменьшенную анимацию и обе темы Telegram. Скриншоты каталога с тестовыми данными: [desktop](ftp-021/desktop.png), [mobile](ftp-021/mobile.png). Проверки на реальных устройствах предусмотрены в PR G.

Основные риски перед приёмкой — доступность акцентов на тёмных поверхностях, положение баннера активной тренировки и взаимодействие с системной темой. Откатить PR можно обычным revert: изменены стили, представление навигации и тесты, миграций и изменений формата данных нет.
