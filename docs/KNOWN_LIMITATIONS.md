# Известные ограничения (живой документ)

Единый список актуальных ограничений. Обновляйте при изменении поведения:
если ограничение снято — удалите пункт, а не оставляйте «на память».

## PWA / офлайн

- «Холодный» офлайн с первого визита невозможен: нужна хотя бы одна успешная загрузка приложения.
- Очередь синхронизации разгружается только при открытом приложении / видимой вкладке; фонового sync при закрытом Mini App нет.
- Данные кэшируются в IndexedDB (`fittracker_rq_offline_v2`, TTL ~7 дней); при недоступности IndexedDB персист молча отключается.

## Auth / безопасность

- Refresh-сессии отзываемые (ротация, reuse → revoke family, logout/удаление). **Access-токены живут до 30 минут** и после logout/удаления не гасятся мгновенно: проверка `token_version` на access-токене запланирована отдельно (#188).
- Legacy-алиасы API (`/auth`, `/achievements`, `/challenges`, `/emergency`) сохранены для обратной совместимости; удаление — отдельный мажор (не входит в v1.0.0).

## Аналитика

- Muscle-signals опирается на legacy-вьюхи (`muscle_load_by_user`, `muscle_imbalance_signals_by_user`), которых нет в текущей схеме. Фича деградирует мягко (эндпоинты не 500), но данные сигналов недоступны, пока вьюхи не переписаны под `workout_logs`/`workout_sets` (Alembic).

## Инструменты / зависимости

- **Vite 8 / Rolldown** — отложено: peer-конфликт Babel 7/8 (стек Jest) + смена движка; отдельная миграция (#243).
- Локальный полный `pytest` на in-memory SQLite под Windows/Python 3.13 флейкает (`Event loop is closed` на concurrency-тесте). Поддерживаемый путь — Postgres (`TEST_DATABASE_URL`), как в CI.
